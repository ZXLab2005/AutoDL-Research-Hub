# AutoDL 研究台发布范围

**Git 根目录仅为当前 `AutoDL-Research-Hub` 平台文件夹。** 目录位置由本机启动入口识别，仓库中的顶层应直接包含 `src/`、`scripts/`、`remote/`、`research/` 和本说明对应的 `github-sync/`。

用户最终要求仅上传这个平台。平台父目录不作为 Git 根目录，其它技能源、技能库、学习资料和文献全部不上传。仓库名称为 `AutoDL-Research-Hub`，展示标题为“AutoDL 研究台”。

排除同步不删除任何本地资料。本文件定义允许发布的范围，不代表第一次提交或推送已经完成；实际结果以同步状态和远端提交为准。

## 纳入

| 路径或文件 | 内容 |
| --- | --- |
| `src/` | VS Code 平台首页、连接管理、SSH 操作记录及目录监视源码。 |
| `scripts/` | Windows 启动、SSH 桥接、远端准备、隧道和扩展打包脚本。 |
| `remote/` | Linux 侧环境准备和可选 Codex 辅助脚本。 |
| `tests/` | 平台测试源码。 |
| `workspace/AGENTS.md`、`Research.code-workspace` | 本地 Codex 操作约定和工作区定义。 |
| `research/Search-R1-repro/` | 正式辅助脚本、使用指南、环境规范、依赖清单与已验收的 CPU 检查快照。 |
| `github-sync/` | 同步器源码、测试、配置样例和使用说明，不包括运行时认证。 |
| 根目录的 Markdown、`launch-config.example.json`、项目声明及 `.cmd` 入口 | 使用教程、相对目录配置样例与启动入口。 |
| `launcher/` | Windows 启动器源码、清单与依赖校验值；编译生成的 EXE 不上传。 |

`research/Search-R1-repro/` 是从本机运行数据中保全的正式副本，包含 8 份正式辅助文件、8 份验收记录及目录说明。其中 `verification/repro/logs/*.json` 是验收报告，属于发布内容。它不是官方 Search-R1 源码，不包含服务器上的 Conda 环境、模型权重、数据集或完整工程备份。

## 不纳入

- **父目录中的全部其它项目**：包括 `_skill_ready/`、`_skill_src/`、`技能安装记录/`、`学习文献/`、`agent学习_fromLIJUN/` 及其它平台外文件。此前讨论的技能 ZIP、上游 ignore 例外和学习资料不再属于这个仓库的发布范围。
- **`app/`**：本机编辑器等运行组件；可以用于本人迁移，对外分发使用不带运行组件的轻量包，不上传源码仓库。
- **`data/`**：SSH 私钥与指纹、连接配置、Codex 登录和会话、扩展、浏览器状态、缓存、临时文件、安装包及运行日志。只有已明确复制到 `research/` 的正式文件进入发布范围。
- **本机 `launch-config.json`**：包含当前机器生成的运行配置，不上传；EXE 按当前平台文件夹自动准备，不需要换机手改固定盘符。
- **`.agent-sync/`**：本机认证、同步配置、临时索引、状态和日志；安全分享包中也不包含这些内容。
- **任意目录中的全部 PDF 文件**：扩展名大小写均适用，继续留在本机。
- 其它认证文件、私钥、令牌、会话数据、`node_modules/`、Python 字节码缓存和生成的运行文件。
- 编译后的 EXE、ZIP/7z/TAR 等归档、数据库与便携包不纳入源码仓库，避免其中包含未检查的个人数据；即使强制暂存，也会由发布检查拦截。

不向父目录递归收集文件，不跟随符号链接或 junction 扩展范围，也不因连接了 SSH 就将服务器文件自动纳入 Git。今后如需发布远端研究源码，应先单独确定它的仓库和发布范围。

## 发布与自动更新

新建文件与修改只在上述平台范围内接受检查。同步器会核对配置的 GitHub 仓库、`main` 分支与 Git 根目录，在安全检查通过后提交和推送。已有人工暂存、远端分叉、认证或内容检查失败时暂停上传；不会使用 force push。

自动同步需要本机监视进程运行、配置有效且网络可用。变化约 30 秒后触发检查，另每 60 秒检查与重试；不承诺逐次保存立即出现在 GitHub。[操作与状态说明](README.md)

便携导出与 GitHub 源码发布不同：默认导出可以包含已下载的运行组件，`-NoRuntime` 则生成轻量包，两种都排除私有运行数据。导出 ZIP 位于 `data/exports/`，不由自动同步上传。解压后运行 EXE 按需准备缺失组件；账号和 SSH 密钥需要本人重新设置，服务器环境需要单独恢复。[便携迁移说明](../PORTABLE-GUIDE.md)
